# Gamma remains calibrated

**Status:** new RAP v4.0 working note, 27 October 2026; no PI approval or evidence upgrade.

The carried gamma value is 16.339 at A−. The recorded MC summary is 16.374 with reported spread 1.005. The exact central difference is 0.035, dimensionless; dividing by the reported spread gives 7/201. Without the uncertainty convention and covariance this is not a certified sigma statement.

The post-hoc comparator performs only that arithmetic. It does not derive gamma, reproduce the calibration or run a Monte Carlo chain. Historical colour-algebra decompositions do not become active derivations by numerical proximity. See manuscript L4 and the anti-target-leakage policy.
