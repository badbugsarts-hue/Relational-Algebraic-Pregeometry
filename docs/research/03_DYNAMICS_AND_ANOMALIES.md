# Action comparisons and imposed-charge controls

**Status:** new RAP v4.0 working note, 27 October 2026; no PI approval or evidence upgrade.

The suite checks the exact equal-block classical action ratio under the external matrix-model assumptions and computes four anomaly sums with the supplied hypercharges. These are algebraic controls, not dynamically selected input data.

A stationary branch is not an exhaustive classification of extrema. A tree-level action comparison is not an all-orders free-energy result. Vanishing anomalies for chosen charges do not uniquely derive those charges, a family structure or the selected block partition. The attractor programme remains open.

The scripts deliberately label these assumptions. No old UIDT mass-gap or spectrum fit is used as a target.
