# External contributions and independent verification

No new external reviewer, counter-signature, replication, institutional endorsement or PI approval is registered by this package. Contributors should supply an immutable source identity, exact command, environment and complete output; specify which declaration or observable was checked; state uncertainty and covariance where applicable; and disclose calibration inputs and target access.

A pull request, AI-generated report, passing Python test or issue closure does not itself change an evidence class. Preserve negative and null results. Evidence upgrades require the corresponding scientific material and an explicit separate record; no automatic upgrade rule is implemented here.
