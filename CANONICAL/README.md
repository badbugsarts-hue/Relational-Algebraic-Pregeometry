# CANONICAL directory

Upper-case `CANONICAL/` matches the requested organizational precedent. Here “canonical” means the package's single declared reference location, not a new scientific freeze or PI approval.

`constants.json` is the machine-readable reference and `constants.schema.json` its schema. `CONSTANTS.md` is generated from it. Evidence, falsification, limitations and ontology documents are freshly written for RAP v4.0. They do not import old UIDT numerical claims. Their snapshot hashes are recorded in the release manifest.
