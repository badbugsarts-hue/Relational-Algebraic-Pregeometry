# Falsification and test gates

## Exact mathematical checks

- A partition violating the interval classification under the declared hypotheses refutes that conditional statement. The analytic proof is in research note 01; the independent finite scan covers only its reported N range.
- A second admissible partition of 6 would refute the declared finite uniqueness result. The suite checks all eleven partitions.
- The general smallest-part-one inference is already refuted by N=7, [4,3]; it is not an active conjecture here.
- A nonzero exact Fraction result would refute the corresponding arithmetic identity under its stated inputs. Floating-point agreement is not substituted for that check.

## Software acceptance

Schema violations, undefined dependencies/source anchors, changed historical PI records, a target-literal/import-boundary failure, unexpected precision mutation, inconsistent independent enumeration, or a failed test return a nonzero process status. Passing those checks validates the stated software conditions only.

The 80-digit diagnostic uses an observed absolute residual threshold of 1e-40; the 100-digit diagnostic uses 1e-60. These thresholds are numerical acceptance criteria, not confidence levels, rigorous error enclosures or mass-gap certificates.

## Physical tests remain separately specified

An empirical claim needs an operator/observable, independently fixed inputs, units, experiment or lattice setup, uncertainty and covariance, preregistered comparison and failure rules. No universal new sigma cutoff is invented for missing protocols. For topology and spectroscopy, complete source and operator matching first. For the 0.66 nm and torsion references, the missing scale or observable bridge must be supplied before numerical resemblance is treated as evidence.

No physical failure threshold in this document supersedes a PI record. Any claimed numerical threshold from the historical corpus must be traced and reviewed before reuse.
